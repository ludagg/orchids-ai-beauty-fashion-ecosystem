✅ DÉJÀ FAIT & FONCTIONNEL :
- **Infrastructure:** Next.js App Router, Tailwind, Drizzle ORM, Postgres.
- **Authentification:** Better Auth (sessions, JWT, roles) est implémenté et connecté.
- **Business/Partner Dashboard:** Pages pour les salons (`/business/*`), gestion des services, staff, produits, réservations.
- **API Shop/Marketplace:** `GET /api/products`, `GET /api/shop/home`.
- **API Video Feed:** `GET /api/videos` (TikTok-like feed, live, following, algorithm base).
- **API AI Stylist:** `POST /api/ai-stylist/chat` avec intégration Gemini (et fallback keyword).
- **Search:** `GET /api/search` recherche globale (produits, salons, vidéos, services).
- **Frontend App:** L'interface client `/app` est structurée avec le bottom nav et le feed de base.

🔧 INCOMPLET / PARTIEL :
- **Video Player (Frontend):** L'API `videos` est robuste (pagination, algorithme smart feed), mais il faut s'assurer que le composant UI (feed TikTok scrollable) exploite pleinement l'API et est performant.
- **Marketplace (Frontend):** `/app/shop` utilise le layout grid, mais le système de filtres complexes ou de panier doit être vérifié.
- **Chat/Messages:** Il existe `/api/conversations/[id]/messages` (à auditer plus en détail la partie realtime).

❌ CASSÉ / DETTE TECHNIQUE :
- `src/app/api/products/route.ts` utilise `products.mainCategory` mais la table a peut-être changé dans `src/db/schema/commerce.ts` (d'après le contexte: `products` utilise `mainCategory`, à vérifier).
- `src/app/api/ai-stylist/chat/route.ts` utilise `products.isActive`. Or, la mémoire "Commerce Schema" indique : *The products table uses status and visibility (not isActive).* Cela causera une erreur 500 sur l'AI Stylist.

🆕 MANQUANT / À CRÉER :
- Modération Admin avancée.
- Webhooks Stripe complets (s'ils ne sont pas finis).
- AI Fit Check (selon mémoire, à confirmer s'il existe).
