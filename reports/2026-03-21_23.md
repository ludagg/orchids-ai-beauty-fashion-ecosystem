### Les décisions techniques que je prends et pourquoi
- **Migration Schema `commerce.ts`** :
  - **Problème** : Les APIs de paiement attendaient `price` et `stock`.
  - **Solution** : J'utilise `salePrice ?? originalPrice` pour le calcul du prix effectif, et `totalStock` pour l'inventaire afin de correspondre au schéma actuel.
- **Optimisation Drizzle** :
  - **Problème** : Dans `api/create-payment-intent/route.ts`, une boucle for était utilisée pour faire des inserts d'items de commande un par un, ce qui augmente les aller-retours DB.
  - **Solution** : Utilisation d'un batch insert (`tx.insert(orderItems).values(orderItemsData)`) pour insérer tous les produits d'une commande d'un coup. C'est le standard de performance recommandé.
