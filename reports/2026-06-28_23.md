## 5. Décisions techniques prises
- **Stockage partiel** : Les informations (height, weight, bodyType) sont envoyées à la route `/api/users/profile/measurements` pour éviter de polluer d'autres routes de profil existantes, et conservées dans la table `users`.
- **Fallback Sizing** : L'intégration d'un algorithme déterministe côté backend garantit que la fonctionnalité de recommandation de taille fonctionne même sans connectivité LLM.
- **Mocking Drizzle** : Dans les tests unitaires (`measurements.test.ts`), le mock de `drizzle-orm` a été structuré pour gérer les appels chaînés `.update().set().where()` avec `vi.hoisted`.
