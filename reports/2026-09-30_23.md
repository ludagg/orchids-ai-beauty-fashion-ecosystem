## Les décisions techniques que j'ai prises et pourquoi
- Utilisation des commandes `bun install`, `bun run lint`, `bun run test`, `bun run build` via `oven-sh/setup-bun@v1` dans le GitHub Workflow afin de garantir des builds plus rapides (car le gestionnaire par défaut de l'application est bun, confirmé via `bun.lock`).
- Fourniture des secrets/variables d'env requises avec des valeurs "dummy" (`DATABASE_URL`, `BETTER_AUTH_SECRET`, `STRIPE_SECRET_KEY`, `RESEND_API_KEY`) dans l'étape "Build project" pour empêcher les erreurs silencieuses et bloquantes lors du rendu statique ou analyse TS côté Next.js pendant le process de build `next build` en environnement CI.
