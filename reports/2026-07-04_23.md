## 5. Décisions techniques prises
- **Fallback IA Local :** Pour prévenir les erreurs lors de la non-disponibilité de Gemini API, j'ai créé une logique locale (`fallbackFitRecommendation`) qui estime la taille selon la taille, le poids, et la morphologie de l'utilisateur de manière algorithmique.
- **Récupération des données utilisateur :** Le composant UI tente d'abord de récupérer les mensurations depuis la session locale (si déjà chargée via auth-client) avant de faire des appels API supplémentaires ou de proposer le formulaire.
- **Mock de Vitest :** J'ai injecté des classes mock de `GoogleGenerativeAI` dans Vitest en utilisant `class { ... }` à l'intérieur du bloc de factory `vi.mock` afin de supporter les instanciations avec `new` côté serveur sans déclencher d'erreurs de hoisting.
