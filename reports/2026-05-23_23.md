## Blocages éventuels
- L'absence de certains secrets de production en base de données ou dans `.env` pourrait ralentir l'intégration complète si des clés tierces (Stripe/Resend) réelles sont nécessaires. Pour l'instant, des mocks/valeurs de test sont utilisés.

## Décisions techniques
- Utilisation de clés dummy/de test pour BetterAuth, Google OAuth, Github OAuth et Stripe dans `.env` pour débloquer le processus de build CI/CD sans dépendre des vrais secrets (la sécurisation en prod se fera via le dashboard de déploiement).
- Désactivation du fallback `turbopack` expérimental dans `next.config.ts` car il cause des crashs de build avec cette version spécifique de Next.js.
