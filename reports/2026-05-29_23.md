## Décisions techniques
- **Résolution des imports circulaires Drizzle** : Pour les appels DB, utilisation de requêtes de haut niveau limitées et indexées au lieu de relations profondes complexes.
- **Mocking Next 15 Request Context** : L'utilisation de `next/headers` dans une route API requiert un mocking spécifique du scope asynchrone Next.js sous Vitest.
- **Fiabilité du parsing LLM** : L'utilisation conjointe d'un prompt d'extraction JSON couplé à un `.replace(/```json/g, "")` garantit qu'aucune erreur de parsing stricte ne bloque l'UI si Gemini retourne du markdown.
