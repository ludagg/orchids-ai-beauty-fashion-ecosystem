## Ce que j'ai fait ce run
* **Optimisation de la performance (Algorithmique)**: Remplacement d'une boucle N+1 de type `Promise.all(creators.map(async () => db.query.videos.findFirst(...)))` par une requête en lot (O(N) -> O(1) requêtes réseau) dans le routeur de l'API `/api/creators`.
* **Réduction de la complexité**: Implémentation d'un algorithme de type in-memory lookup via `Set` (complexité globale ramenée à O(N+M)).
* **Amélioration environnement de dev**: Fix d'une erreur d'authentification bloquant le `bun run build` via injection de `BETTER_AUTH_SECRET`.
* **Création de benchmarks**: Création et exécution de scripts `benchmark-creators.ts` pour chiffrer l'optimisation (le temps d'exécution est passé de 2323.81 ms à 315.54 ms, soit une réduction de plus de 85% !).
