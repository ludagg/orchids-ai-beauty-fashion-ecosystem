## 5. Décisions techniques prises et pourquoi
- **GitHub Actions pour la CI** : Choix standard pour les projets hébergés sur GitHub. L'utilisation de `oven-sh/setup-bun` accélère les temps d'installation des dépendances.
- Injection de variables factices pour le `next build` : Permet de s'assurer que Next.js réussit l'étape de compilation / prerendering sans casser à cause d'erreurs d'initialisation de la DB ou de clients API manquants.
