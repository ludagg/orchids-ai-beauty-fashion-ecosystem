## 5. Décisions techniques prises
- **Stockage des mensurations** : j'ai décidé de conserver les attributs `height`, `weight` et `bodyType` directement dans la table `users` pour qu'ils soient récupérables facilement via la session (`authClient.useSession()`), réduisant ainsi le nombre d'appels API supplémentaires.
- **Fallback IA** : j'ai implémenté une fonction algorithmique basique de fallback `fallbackFitMatch` dans la route AI Fit pour assurer un niveau de service même si l'intégration API Gemini échoue ou si les variables d'environnement manquent.
