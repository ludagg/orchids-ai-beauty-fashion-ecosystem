## Décisions techniques prises
- **Optimisation des requêtes DB en mémoire**: Remplacement systématique des parcours séquentiels dans les gestionnaires d'API (le pattern `Promise.all` + `.map` + `findFirst`/`findMany` de Drizzle) par des requêtes de lot (batch queries) à l'aide de `inArray()`. Cela permet de réduire les allers-retours vers la base de données et donc le temps de latence réseau, crucial pour l'objectif cible de < 100ms API latency (p99) spécifié dans l'objectif de l'application "Scale 1 Milliard d'Utilisateurs". Le regroupement se fera en mémoire (RAM) via des objets de type `Map`, plus rapide que l'équivalent O(N*M).
